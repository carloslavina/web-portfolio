# AGENTS.md

## Context

This is a Stitch design system repo. The single source of truth is `DESIGN.md`, which defines colors, typography, spacing, and component patterns for an experimental artist portfolio (Minimalist + Brutalist aesthetic).

## Workflow

- When building or editing UI, read `DESIGN.md` first and follow its tokens and component specs.
- Use the `design-md` or `stitch-design` skill for design synthesis and generation tasks.
